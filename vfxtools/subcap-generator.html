Subcaps Text Generator

Generate Avid subcap files from CSV turnovers with flexible field mapping

← Back to VFX Tools

How to use:

  • Upload a CSV file with timecode and shot data (e.g. from ScriptSync or a turnover spreadsheet)
  • The CSV must contain Counts::ReelTC_in (timecode in) and Counts::Cut (duration in frames) columns
  • Select which fields to include as subtitle text — they'll appear tab-separated in the subcap
  • Set your project frame rate (default 24fps)
  • Generate and download the .txt file to import into Avid as subcaps
