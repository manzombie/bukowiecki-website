ALE Merge Bench

Merge a vendor submission CSV into an Avid-exported bin ALE and get a re-importable ALE that fills the bin's columns in one go — with every match shown so you can correct it before export. The match keys (Name + exact timecode) and all structure are carried through byte-for-byte; only the columns you choose are written.

Everything stays on your machine — both files are read and merged locally in your browser. Nothing is uploaded, sent or stored anywhere.

Column mapping CSV field → ALE column (writable only; match-keys are read-only)

Avid only accepts a merge into editable columns — your own custom columns plus free fields like Comments, Vendor, Edit_Note. Columns Avid owns/derives (Package Name, Start, End, Tape, Source File, Duration, Drive…) are flagged ⚠ and won't import on merge — set those in the bin directly. Tip: to land data Avid would otherwise ignore, create a custom column in the bin (e.g. Package) and map to that.
